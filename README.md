# المساعد الذكي — Smart Assistant

تطبيق Android حقيقي مبني بـ Kotlin + Jetpack Compose + Room لإدارة العملاء والأرصدة والأصناف والمخزون والاستحقاقات والتقارير.

## نطاق التطبيق
- إدارة العملاء والأرصدة الحالية فقط.
- حفظ اتجاه الرصيد: عليه / له دون تحويله إلى معاملات محاسبية.
- إدارة الأصناف والكميات والحد الأدنى وتواريخ الانتهاء.
- الاستحقاقات والمتابعة والإشعارات.
- تقارير ونسخ احتياطي واستعادة وسجل نشاط.
- استيراد Excel/XLSX وCSV وPDF النصي وقواعد بيانات SQLite/Room مع شاشة مراجعة واعتماد قبل الحفظ.
- دعم تطبيع الأسماء والأرقام العربية واكتشاف الملفات المكررة.
- المساعد الذكي الحالي يعمل محلياً على بيانات التطبيق، ولا يرسل بيانات العملاء إلى خدمة خارجية.

## مسار الاستيراد
اختيار الملف → تحليل → مراجعة → اعتماد/إلغاء → نسخة احتياطية → حفظ ذري في قاعدة البيانات.

الاستيراد لا ينفذ مبيعات أو مشتريات أو سندات دفع أو قيود يومية.

## البناء
البناء يتم عبر GitHub Actions فقط، ولا يحتاج Flutter أو Gradle محلياً على Termux.
- workflow_dispatch للبناء اليدوي.
- كل push على main أو final-smart-assistant يشغّل بناء APK وAAB.
- الوسوم v* تشغّل البناء أيضاً.

بعد نجاح البناء، ستجد app-release.apk وapp-release.aab في Artifact باسم release-binaries.
